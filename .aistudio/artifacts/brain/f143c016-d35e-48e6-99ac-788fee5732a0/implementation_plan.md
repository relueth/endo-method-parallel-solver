# Windows PC 自前サーバー化 & Cloudflare Tunnel 世界公開 実装計画

Windows PCを親サーバー（マスターノード）として稼働させ、世界中のPC・スマートフォン・タブレットから安全かつポート開放不要でアクセス・分散計算に参加できるようにするための構成手順とアプリ内専用ガイドの実装計画です。

---

## ユーザー確認事項・決定事項

> [!IMPORTANT]
> 前のターンでユーザー様より以下の構成が指定・確定されました。

* **公開方式**: **Cloudflare Tunnel**（無料・ルーター設定/ポート開放不要・HTTPS自動暗号化・DDoS防護）
* **サーバーPCのOS**: **Windows** (Windows 10 / 11)

---

## 1. 概要と構成アーキテクチャ

自宅や研究室のWindows PC上で親サーバー（Node.js + Python + SQLite）を動かし、Cloudflareのエッジネットワークを経由して暗号化トンネル（アウトバウンド接続）を接続します。外部のスマートフォンやPCは、Cloudflareが発行するセキュアなURL（`https://xxxx.trycloudflare.com` または独自ドメイン）にアクセスするだけで、ルーターの設定変更なしに直接親サーバーとWebSocket/HTTP通信が可能になります。

## 2. ユーザー体験 & 実装内容

アプリ内の「配布用コード & LAN展開手順」タブおよび各コンソール画面を拡張し、Windows PCで誰でも迷わず3ステップで世界公開できるように以下のガイドおよびスクリプト提供機能を統合します。

### ① Webコンソール内の専用ガイド追加 (`CodeInspector.tsx`)
* **「Windows PCをサーバーにして世界公開（Cloudflare Tunnel）」** タブ/セクションを新設。
* **ステップ1: Windows環境の準備**:
  * Node.js (v18以上) と Python 3 のインストール（wingetコマンド1行で入る手順付き）。
* **ステップ2: サーバーの起動**:
  * アプリ一式のダウンロードと `npm run build && npm run dev`。
* **ステップ3: Cloudflare Tunnel の起動（2通りの選択肢）**:
  * **A. クイックトンネル（アカウント登録すら不要・即座にURL発行）**:
    ```bash
    winget install --id Cloudflare.cloudflared
    cloudflared tunnel --url http://localhost:3000
    ```
    実行するとターミナルに `https://xxxx.trycloudflare.com` が表示され、スマホから即座にアクセス可能になります。
  * **B. 固定URL / 独自ドメインでの常時運用（Zero Trust Dashboard）**:
    PC起動時に自動でバックグラウンド実行（Windowsサービス化）する手順。

### ② Windows用ワンクリック自動起動スクリプトの提供
* PCの電源を入れた後、ダブルクリックするだけで親サーバーとCloudflare Tunnelを同時に立ち上げるバッチファイル（`start-cluster.bat`）の配布コードを追加。
* 起動時に生成された公開URLを自動でコンソールに表示し、QRコード生成リンクを提示する親切設計。

### ③ アプリ内「📱 別の端末・スマホからアクセス」モーダルの強化
* モーダル内に「自前PCでCloudflare Tunnelを動かしている場合の入力欄」を追加（トンネルURLを入力すると、その場でスマホ用QRコードが生成されてスキャンできる機能）。

## 3. 主な設計判断とトレードオフ

1. **Quick Tunnels（登録不要モード）の優先案内**:
   * *理由*: Cloudflareアカウントやドメイン購入がなくても、Windowsで `cloudflared tunnel --url http://localhost:3000` を叩くだけで30秒で世界中からアクセス可能なURLが発行されるため、初心者にとって最も参入障壁が低いです。
   * *固定化への拡張*: 長期的に同じURLで運用したい方向けに、Cloudflare Zero Trustダッシュボードを使った固定ドメイン設定手順も併記します。

2. **WebSocket（/ws/worker）の完全サポート**:
   * Cloudflare Tunnelは追加設定なしで標準でWebSocket通信をサポートしているため、本アプリのマルチコアWebワーカー機能（リアルタイムタスク配分・ハートビート・解の集約）がそのまま世界中から動作します。

3. **セキュリティの担保**:
   * ルーターのポートを開放しないため、ポートスキャンや直接侵入のリスクをゼロにします。
